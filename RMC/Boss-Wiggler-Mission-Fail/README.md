## Fail Wiggler Boss Race If Wiggler Wins

This is a gecko code that fails the Wiggler boss race once the object enters the finished state. The code "[Add Mission Mode 'Failed' Features [456]](https://mariokartwii.com/showthread.php?tid=2740)" is required for this code to function properly. Unless the code "[Enable Balloons in Mission Mode [QB22]](https://mariokartwii.com/showthread.php?tid=2809&pid=19477#pid19477)" is also used, a fix for the game overwriting the failure state after updating the timer is optionally included. Assemble the main code using PyiiASMH or Codewrite.
