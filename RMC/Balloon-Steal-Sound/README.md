## Play the Balloon Spawn Sound When a Player Steals a Balloon

This is a gecko code that plays an unused variation of the balloon spawning sound, "SE_CC_BALLOON_TAKE" or sound ID 0x1f8, when a player uses a Mushroom to steal a balloon, just like in Mario Kart DS. 

Assmeble this code using PyiiASMH. You may also use Codewrite if you don't want to use the unused sound effect and instead use its used variant, 0x1f5 or "SE_CC_BALLOON_GET."
