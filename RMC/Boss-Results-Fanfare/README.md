## Play the Boss Win Music After Beating a Boss Tournament/Competition [QB22]

This is a gecko code that fixes a bug that causes playback failure of the Boss Mission win fanfare + results. The unused mission mode is not supported for now. Inspired by mkwcat's fix from their [https://github.com/mkwcat/MKWTM Tournament Museum] project, but is a different implementation with the goal of stamping out the bug at its root, hence the new hook address.
