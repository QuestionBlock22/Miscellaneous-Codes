## CPU Rubber Banding Probability Modifier

This is a gecko code that lets you set the chance that a CPU activates its speed advantage to as high or as low a value as possible. Due to code differences between the South Korean version and every other version, the form its code takes differs from the others. For every version except the South Korean version, checks for Tournament Mode have also been included, so you can safely go online with this code. Assemble this code using PyiiASMH or Codewrite.
